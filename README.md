## Why this list exists

There are thousands of AI launches, and product pages alone do not reveal whether a tool is finding an audience. Web traffic is a useful discovery signal: it can help researchers, operators, builders, and buyers identify destinations worth evaluating.

It is not a quality score, a revenue estimate, an active-user count, or a recommendation. A highly visited domain can serve several products, documentation, marketing pages, and non-AI workflows. This repository makes that limitation explicit rather than hiding it behind a leaderboard.

## How to read the numbers

> [!IMPORTANT]
> The visit number is an estimate for the associated web domain, not a direct measurement of one product feature, API, paid seat, or active user.

- **Domain-level measurement:** A destination can host product pages, documentation, marketing pages, and other services. More than one HuntAI product may share a domain; this README intentionally keeps one representative row per selected domain.
- **A discovery signal, not a verdict:** Traffic can reveal attention and awareness. It does not establish output quality, safety, cost, privacy, enterprise readiness, or fit for a particular task.
- **A dated snapshot:** Rankings move. The numbers here correspond to the June 2026 source snapshot and should be read alongside the [live HuntAI ranking](https://huntai.tools/ranking).
- **Global rank may be unavailable:** A dash means the source record did not provide a usable global-rank value. It does not mean zero traffic.

## Selection and methodology

This repository is a curated view of HuntAI's broader public ranking, designed to avoid misleading attribution.

1. Start with HuntAI-listed products carrying an Artificial Intelligence topic and a positive monthly-visit estimate.
2. Exclude Product Hunt domains from traffic attribution.
3. Deduplicate on the associated domain, preserving one representative HuntAI record per domain.
4. Exclude shared social networks, link shorteners, and broad parent/company domains where the total site traffic would not be a meaningful signal for a particular AI destination.
5. Sort the retained rows by the associated domain's monthly-visit estimate.

The data file preserves the exact numeric estimate, global rank where provided, associated domain, source snapshot month, and the HuntAI profile URL for each row. For HuntAI's fuller methodology and live coverage, see [HuntAI Methodology: Ranking AI Tools by Real Traffic](https://huntai.tools/methodology).

## Updating the snapshot

The intended update process is deliberately conservative:

1. Retrieve a newer published HuntAI snapshot.
2. Preserve the source month and the retrieval date.
3. Reapply the domain-level deduplication and shared-domain exclusions.
4. Update both the JSON file and the rendered table in the same pull request.
5. State whether any row changed because of coverage, mapping, or traffic movement.

Please do not replace missing traffic with a different platform's numbers, a social post's reach, or an unverified estimate. A missing value is more honest than a fabricated one.
